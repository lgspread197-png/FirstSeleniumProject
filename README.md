# FirstSeleniumProject

Учебный проект по автоматизированному тестированию веб-приложения Telran.

Цель проекта: научиться создавать, запускать и поддерживать автоматизированные UI-тесты с использованием Python.

Тестируемое приложение: https://telranedu.web.app/login

Используемые технологии:

Python — язык программирования

Selenium WebDriver — автоматизация браузера

pytest — фреймворк для тестирования

Google Chrome — браузер для запуска тестов

Git / GitHub — система контроля версий
